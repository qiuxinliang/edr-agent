FDSecurity 最终用户许可协议

1. 本软件仅允许在组织授权的受管终端上安装和运行，用于终端安全检测、响应、取证和运维管理。

2. 本软件会采集必要的安全遥测，包括进程、命令行、文件、网络、注册表和运行健康指标，用于威胁检测、误报治理和响应闭环。

3. 您不得绕过安全控制、篡改安装目录或将本软件部署在未授权环境。卸载、升级和策略变更应通过组织授权流程完成。

4. 本软件按组织策略接收检测规则、采集策略和版本更新，以维持防护有效性和资源占用边界。
